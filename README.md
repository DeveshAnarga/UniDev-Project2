# Dental Database Query System (Monash New Smile)

Relational and document-store query work for a dental clinic data model — patient records, appointments, and services.

## What I built

- Relational algebra and SQL queries for efficient retrieval
- MongoDB / NoSQL commands alongside the relational layer
- End-to-end coverage of list, filter, and aggregate-style operations used in clinic workflows

## Stack

SQL · Relational algebra · MongoDB
